DEMO GUIDE

무엇을 검증할 수 있나요?

이 공개 실험실은 DeepSolar Korea의 데이터 검수와 학습 흐름을 체험하는 정적 웹 앱입니다.

이 사이트에서 바로 가능한 것

  • 24개 합성 영상과 라벨 확인
  • 학습용 라벨 수정·저장·JSON 내보내기
  • 원본, 2·4·8배 해상도 저하 비교
  • 브라우저에서 실제 로지스틱 기준선 학습
  • 분리된 평가 데이터의 지표·예측 비교

별도 서버 환경에서 검증할 것

실제 위성 영상 업로드와 운영 데이터 관리, PyTorch·TinyUNet 추가 학습, GPU 실행, AWS 배포 및 실제 한국 지역의 정확도 평가.

라벨과 실험 기록은 이 기기의 브라우저 저장소를 사용합니다. 비공개 모드·저장소 제한·사이트 데이터 삭제 시 기록이 사라질 수 있으니 필요한 결과는 내보내세요. 저장 공간을 위해 최근 12개 실험을 보관합니다.
